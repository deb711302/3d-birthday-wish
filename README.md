# 🎉 3D Animated Birthday Wish Website

An impressive, interactive 3D animated birthday wish website designed to impress your loved ones!

## ✨ Features

- **3D Animated Objects** - Rotating cake, balloons, and stars using Three.js
- **Particle Effects** - Confetti animations and particle trails
- **Interactive Elements** - Click buttons to trigger celebrations
- **Sound Effects** - Beautiful musical notes on interaction
- **Countdown Timer** - Suspenseful countdown to make a wish
- **Responsive Design** - Works perfectly on desktop, tablet, and mobile
- **Smooth Animations** - Professional CSS animations and transitions
- **Birthday Wishes** - Personalized messages and wishes

## 🚀 Getting Started

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Click the "Celebrate!" button to start the party!

## 🎨 Customization

### Change the Birthday Message
Open `index.html` and modify the message in this section:
```html
<p id="message" class="message">Your custom message here!</p>
```

### Change the Birthday Wishes
Modify the list in the "Birthday Wishes for You" section:
```html
<li>✨ Your wish here!</li>
```

### Change Colors
Edit `styles.css` to modify:
- Gradient backgrounds
- Button colors
- Light colors
- Text colors

### Change 3D Objects
Edit `script.js` to modify:
- Object colors
- Object sizes and positions
- Rotation speeds
- Add new 3D shapes

## 🎭 Interactive Features

- **Celebrate Button** - Triggers confetti and acceleration of 3D objects
- **Sound Toggle** - Turn sound effects on/off
- **Mouse Move** - Creates particle effects as you move the mouse
- **Click Anywhere** - Creates a burst effect at your cursor

## 🛠️ Technology Stack

- **Three.js** - 3D graphics library
- **HTML5** - Structure
- **CSS3** - Styling and animations
- **JavaScript** - Interactivity and animations
- **Web Audio API** - Sound effects
